## Visual Contract

1. 采用浅色、细分隔线、窄侧导航和表格优先的工作台，而不是大卡片仪表盘。
2. 色彩不是装饰性渐变：蓝色表示导航、主操作和可点击链接；紫、绿、橙、红、青用于真实的 `status`、`single_select`、`multi_select` 和关系状态标签。颜色由已有字段值稳定映射，不能捏造业务状态。
3. 高饱和色只在标签、重点操作和选中态中占小面积，表格与正文保持高对比的白底阅读面。
4. 真实后端能力必须给出入口；没有受控 API/权限契约的能力只能明确标为“即将上线”，不得伪装为可用。
5. 核心交互必须可达：工作区/Base/团队 Bot/AI 对话互相可进入；导入、建表、建字段、建视图、配置视图、建记录、记录详情、右键菜单和草稿确认均保持键盘可关闭或可回退。
